# DIS-CONNECT-WEB-APP

Used for Orbital Project, this is a web-based dashboard for HR officers to manage and resolve tickets.

# Overview / Home Page
Provides a high-level summary of ticket activity, scholar metrics, notifications, and system health. HR officers can see statistics on the number of open tickets and their SLA compliance rate. They can also see how their current performance compares to monthly targets.

# Tickets
HR officers can view and manage open tickets under Tickets > Open Tickets. The tickets are presented in card view and there are four different columns representing different ticket statuses: "In Review", "Waiting", "Resolved", and "Overdue". Ticket statuses can be updated on this screen using the dropdown menu on each ticket card.
